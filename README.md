# Dyo — public pages

Public website for **Dyo (דיו)**, a Hebrew newspaper app for iPhone, iPad and Mac. Served with GitHub Pages from `main` (root).

| Page | Hebrew (primary) | English |
| --- | --- | --- |
| Home | https://avitsadok.github.io/Dyo-app-public/ | https://avitsadok.github.io/Dyo-app-public/en/ |
| Support | https://avitsadok.github.io/Dyo-app-public/support/ | https://avitsadok.github.io/Dyo-app-public/en/support/ |
| Privacy policy | https://avitsadok.github.io/Dyo-app-public/privacy/ | https://avitsadok.github.io/Dyo-app-public/en/privacy/ |
| Terms of use | https://avitsadok.github.io/Dyo-app-public/terms/ | https://avitsadok.github.io/Dyo-app-public/en/terms/ |

Plain static HTML, no build step (`.nojekyll` turns Jekyll off). Styles live in `assets/style.css`.

When something the app collects changes, update **both** privacy pages and the "last updated" date, and the App Store privacy label to match.
